## Outcome and implementation context

Implement the proposed `son share <id>`, `son unshare <id>`, and write-time `--shared` behavior around node visibility. The draft defaults to private: no memory leaves the machine unless explicitly shared. Inspect `src/store.rs`, `src/cli.rs`, `src/app.rs`, and export/import handling. Local organizational collections are not remote access controls.

The full proposal, API sketch, schema foundations, and original open questions are in [the parent design](13.md). They are proposals, not settled v2 decisions. This migration does not authorize implementation.

## Dependencies

Coordinate with #13.3 and #13.5 before deciding remote effects of unsharing.

## Acceptance and validation

Private records are excluded from push candidates; explicit sharing makes a record eligible. Share/unshare state survives persistence and agreed transfer paths. Changes are auditable and consistent with v1 history.

Run the repository checks in [CLAUDE.md](../CLAUDE.md) and isolate test databases, configuration, and credentials.
