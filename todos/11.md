## Outcome and implementation context

Create a reproducible evaluation with two different agents, a coding scenario, and a noncoding scenario. Have one agent save knowledge, then start a fresh session with the other agent and observe whether it recalls and uses that knowledge through the installed instructions. Include a duplicate candidate, an outdated fact with newer evidence, and an instruction-like stored note. Use disposable databases/configuration and fictional non-sensitive data.

Measure useful retrieval and application, recall before acting, write-back after learning, duplicate avoidance, correction of outdated memories, and respect for the [#10](10.md) rule. Existing `son stats` hit rate measures any result, not usefulness; use a scored transcript/checklist for relevance and correctness rather than presenting hit rate as proof of success. Record versions, prompts, setup, expected outcomes, and observed failures so another agent can repeat the evaluation. Mocked CLI tests are not a substitute for the real agent experiment.

Acceptance: both scenarios have documented results from separate agent sessions, failures become concrete follow-up items, and logs contain enough evidence to assess behavior. If agent access is unavailable, prepare the runnable procedure and report the unexecuted portion honestly.

Decision (William, 2026-11-11): Use **Claude Code and Codex**, testing memory handoff in both directions: Claude Code writes and a fresh Codex session recalls, then Codex writes and a fresh Claude Code session recalls. Cover both directions for the coding and noncoding scenarios, with isolated fixtures so one run does not supply unintended context to another. Record actual agent versions and results. This selects the evaluation agents; it does not start the evaluation now. Obtain any necessary account/session access from William; do not assume it.

Decision (William, 2026-11-11): Use **household maintenance with fictional data** for the noncoding scenario. Include appliance facts, maintenance decisions/preferences, and open/completed todos; exercise duplicate avoidance, correction of outdated information, and handoff of unfinished work. Use this scenario in both agent directions alongside the coding scenario. Do not use real household details or secrets. The evaluation-agent and noncoding-workflow questions are settled.
