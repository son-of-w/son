## Status (2026-11-11)

Checked: the releases hold both Mac archives (and both Linux archives) with `SHA256SUMS`. The GitHub account Raxvis has no `homebrew-*` repository, so there is no tap yet.

Prepared: `scripts/homebrew-formula.sh [version]` prints the formula for a published release. It reads the checksums from the release's `SHA256SUMS`, chooses the archive by processor on macOS and Linux, installs only the binary, does not run `son init`, and has a `test do` block (`son --version`, then a save and a recall in a throwaway database). Tried against v0.1.11: the output passes `ruby -c`. Not tried: `brew install`, `brew test`, `brew audit` (they need the formula in a tap).

The repository has no LICENSE file, so the formula says `license :cannot_represent`. Homebrew's own audit wants a license for a public tap.

Waiting for: where to publish. The usual place is a public repository `Raxvis/homebrew-son` holding `Formula/son.rb`; users then run `brew install raxvis/son/son`. No repository was created.
